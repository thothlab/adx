# ADX — Android Device eXplorer

Доступ к файлам Android-устройства по USB через MTP. macOS, Windows, Linux.

Аналог Android File Transfer, у которого три заявленных отличия — и все три проверяемые:

1. Сессия переживает сон компьютера, блокировку экрана и перевтыкание кабеля.
2. Устройство, захваченное чужим процессом, названо поимённо и освобождаемо из интерфейса.
3. Долгая передача не замораживает интерфейс: чтение идёт окнами, освобождая единственную сессию MTP между ними.

**Статус: в разработке.** Готов каркас (T00). Работы с устройством пока нет.

## Разработка

```bash
pnpm install
pnpm tauri:dev      # окно приложения
pnpm typecheck && pnpm lint && pnpm test
cargo test
```

Dev-сервер слушает **1430/1431**, а не дефолтные для Tauri 1420/1421: на той же машине
на дефолтной паре живёт Pane, и при `strictPort` пересечение валит `tauri dev`.
Порт задаётся в двух местах — `vite.config.ts` и `devUrl` в `src-tauri/tauri.conf.json`.

## Устройство репозитория

```
src/                  SolidJS: компоненты, сторы, i18n, стили
src-tauri/            команды и события Tauri, точка входа
crates/adx-core/      модель, состояния, ошибки — без Tauri и без MTP
crates/adx-mtp/       единственный крейт, который знает про mtp-rs
```

Два правила, которые проверяются, а не подразумеваются:

- **Вне `crates/adx-mtp` нет упоминаний `mtp_rs::`.** Библиотека молодая (0.30.0), версия
  пинуется точно; смена бэкенда не должна доходить до UI.
- **Фоновые задачи — только через `tauri::async_runtime::spawn`.** `tokio::spawn` в `setup()`
  Tauri роняет macOS-сборку с SIGABRT ещё до появления окна.

Нативные диалоги (`confirm`, `prompt`, `alert`) мертвы в Tauri WKWebView — запрещены правилом eslint.

## Известные ограничения по платформам

**macOS.** Системный агент `ptpcamerad` перехватывает MTP/PTP-устройства при подключении
и блокирует доступ другим приложениям; установленный Android File Transfer делает то же.
ADX показывает это отдельным состоянием и предлагает освободить устройство — только по
явному действию пользователя. Прав администратора не требуется: агент живёт в
пользовательском домене `gui/$UID`.

**Windows.** Работает через нативный WPD, установка драйверов и Zadig не нужны.

**Linux.** Нужны udev-правила для доступа к USB без root — файл `99-adx.rules` и шаг установки
появятся вместе с упаковкой.
